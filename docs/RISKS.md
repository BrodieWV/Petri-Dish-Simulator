# Risks

1. Simulation complexity stalls development. Start with one nutrient, simple fields, and four archetypes.
2. Scientific claims mislead players. Use broad archetypes, accuracy labels, and later expert review.
3. Slow visuals cause churn. Accelerate time and provide growth fronts, events, feedback, and objectives.
4. Outcomes feel random. Use seeds, limiting factors, causal timelines, and constrained randomness.
5. Content becomes code-heavy. Use schemas, reusable behaviours, visual profiles, and validation.
6. Mobile performance fails. Use a small grid, fixed rates, pooled visuals, caps, and early profiling.
7. Save changes break experiments. Version schemas and test migrations.
8. Petri Terrarium scope arrives too early. Keep layers, animals, and complex chemistry outside MVP.
9. Child safety/pathogen concerns. Avoid actionable culturing instructions and use educational framing.
10. Monetisation harms play. No active-experiment interstitials or pay-to-rescue mechanics.
