# Analytics Plan

## Questions

Do players understand setup? Does the dish become interesting quickly? Which variables cause failure? Do players inspect and intervene? Does failure lead to another attempt? Where does onboarding lose players?

## Events

App launch, setup start, experiment start, selections, initial settings, interventions, inspection, discoveries, alerts, pause/speed changes, save resume, completion, abandonment, outcomes, guided/challenge completion, and rewarded-ad flow.

## Properties

Seed, organism, medium, challenge, simulation duration, real duration, intervention count, outcome, limiting factor, device tier, app version, and content version.

## KPIs

Tutorial completion, time to visible growth, time to intervention, experiments per first session, restart after failure, Day 1/Day 7 retention, session length, crash-free sessions, save-resume success, and rewarded-ad opt-in.

## Privacy

Collect only data necessary to answer product questions. Avoid player-entered text unless clearly disclosed and required.
