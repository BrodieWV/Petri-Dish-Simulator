# Test Strategy

## Simulation tests

Tolerance curves, ideal growth, resource limits, lethal conditions, consumption, waste, spread, competition, dormancy, recovery, and seed reproducibility.

## Determinism tests

Same seed/actions produce the same snapshots; save/resume matches uninterrupted play; frame rate and visual randomness do not alter simulation outcomes.

## Content validation

Duplicate IDs, missing references, invalid ranges, negative rates, impossible objectives, missing visuals, missing scientific labels, and unsupported migrations.

## Integration tests

Setup, interventions, discoveries, challenge outcomes, profile rewards, and saving.

## Manual tests

First experiment, touch sizes, aspect ratios, large text, colour accessibility, pause/resume, backgrounding, low-memory recovery, and offline use.

## Performance

Simulation step time, frame time, memory, save duration/size, battery, thermal behaviour, and long-running stability.

## Golden scenarios

Ideal growth, dry collapse, heat collapse, nutrient depletion, dormancy/recovery, contamination takeover, and stable equilibrium.
