# Experiment Selection Implementation

## Phase 2 scope

The runtime setup panel allows the player to browse every validated organism and medium in the active `SimulationDefinitionCatalog`. It shows the player-facing description and scientific accuracy label before a selection is applied.

Browsing does not mutate the running simulation. Pressing **Start experiment** explicitly restarts the current seed with the selected stable organism and medium IDs. **Cancel** closes the panel without changing the experiment. This keeps comparisons reproducible and uses the existing save-schema-v3 persistence path.

The panel is generated by `RuntimeBootstrap`; no scene, prefab, model, material, camera, or authored transform is required or changed. Content remains data-driven: adding a reviewed definition to the catalog makes it available without organism-specific presentation code.

## Save and compatibility behaviour

- `ExperimentController.StartNew(seed, organismId, mediumId)` validates both IDs before replacing the simulation.
- The selected IDs and definition versions are captured in schema-v3 saves and resolved through the catalog on load.
- Restart same seed and restart new seed preserve the active selection.
- Schema-v2 saves still migrate to `rapid-bacterium` and `nutrient-agar`.
- Missing or invalid catalog entries fail through the existing controlled validation path.

## Manual Unity verification

1. Enter Play Mode and confirm the current organism and medium names appear above the dish.
2. Tap **Setup** and confirm the panel overlays the dish without changing pause or speed state.
3. Browse organisms and media in both directions; confirm the names, descriptions, and accuracy labels update.
4. Tap **Cancel** and confirm the running experiment is unchanged.
5. Reopen the panel, choose a different setup, and tap **Start experiment**. Confirm the same seed restarts with the chosen content.
6. Save, change setup, load, and confirm the saved organism and medium return exactly.
7. Verify Standard and Large text modes on narrow and tall portrait profiles, including safe-area devices and touch targets.
