# Proposed Project Structure

- `Assets/PetriDish/Content` — organisms, media, dishes, challenges, discoveries, visual and audio profiles.
- `Assets/PetriDish/Simulation` — core state, systems, randomness, snapshots, validation.
- `Assets/PetriDish/Application` — experiment lifecycle, interventions, saving, progression, analytics.
- `Assets/PetriDish/Presentation` — dish rendering, UI, camera, audio, accessibility.
- `Assets/PetriDish/Platform` — lifecycle, ads, achievements, analytics providers.
- `Assets/PetriDish/Development` — overlays, inspectors, seeds, presets.
- `Assets/PetriDish/Tests` — simulation, integration, validation, save fixtures.
- `docs`
- `data`
