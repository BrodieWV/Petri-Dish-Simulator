# GitHub Reference Notes

Research date: 26 July 2026

## Main reference

`anthonysgro/microbial-ecology-sim` demonstrates persistent environmental state on a two-dimensional grid, independent heat/chemical/metabolic systems, local interactions, deterministic seeds, runtime overlays, edit tools, snapshots, validation, and separation of simulation from visualisation.

## Adopted ideas

Deterministic experiment seeds, local environmental fields, independent systems, inspection overlays, data-driven configuration, validation, and core/presentation separation.

## Differences

Petri Dish Simulator is mobile-first and player-facing. It prioritises guided learning, readable outcomes, progression, accessibility, and simplified ecology rather than an unconstrained scientific engine.

## Rejected for MVP

Fully emergent species, native high-performance engine requirements, complex child-facing chemical budgets, command-line configuration, desktop-only editing, and unrestricted cellular automata.
